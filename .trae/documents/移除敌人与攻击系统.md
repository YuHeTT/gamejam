# 移除敌人与攻击系统（转向 2D 纯解谜）

## Context

项目 `gamejam` 是一个 Unity 2022.3 的 2D 动作平台游戏，玩家具有连击、弹反/拼刀、分身等战斗机制，并配有骷髅敌人。
用户希望把游戏逐步改造为 **2D 纯解谜游戏**，因此需要清除所有**与敌人有关**、**与攻击有关**的**代码 + 美术/动画/场景资产**，为后续解谜玩法腾出干净基础。

范围（已与用户确认）：
1. 删除整个技能系统（含分身 Clone）。
2. 删除顿帧 / 相机震动 / 受击闪白等仅服务战斗的打击感工具。
3. **代码与资产一并删除**：同时清理场景中的敌人/攻击对象与组件、相关动画剪辑、动画控制器、Prefab、敌人美术。

保留：移动、跳跃、二段跳、冲刺位移、蹬墙滑落/蹬墙跳、相机与视差背景、玩家状态机基础设施、`PlayerManager`、UI/Tiles 等非战斗资产。
`Player_AC.controller` 保留（仅清除其中的攻击/反击状态与参数）。

> 安全前提：执行前建议先 `git commit` 当前状态（当前仅有 `ProjectSettings.asset` 一处改动），以便 YAML 编辑出问题时回滚。
