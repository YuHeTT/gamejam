# 墓碑：与玩家碰撞开关 + 空中放置并粘附移动地面

## Context

项目已有墓碑系统（「墓」道具按 S 放置、W 传送）：

- `TombstoneService`（场景单例，存在于 `Assets/Prefabs/墓碑控制.prefab`）负责生成墓碑：`TryPlaceAtPlayerFeet()` 目前**强制要求玩家着地**，且**只能落在射线命中的地面点**上。
- 墓碑预制体 `Assets/Prefabs/墓碑（占位）.prefab`：根对象在 `Tombstone` 层(9)，带 `BoxCollider2D`(非 Trigger 1x1) + `Rigidbody2D`（`BodyType=Static`）+ `TombstoneMarker`。
- `PlayerTombstoneTeleport` 通过 `TombstoneService.GetTeleportFeetPosition()` → `TombstoneMarker.FeetWorldPosition`（子物体「墓碑底」的世界坐标）取传送目标。

用户希望新增两个 Inspector 开关：**①墓碑与玩家是否有碰撞判定**；**②墓碑是否可以在空中放置**。空中放置后墓碑悬停不下落，若有**移动的地面**碰到它，就粘附到该平台上并随其移动。

## 已核实的关键事实

1. `ProjectSettings/TagManager.asset`：层 9 已命名为 `Tombstone`；层 3=`Ground`、6=`Player`、8=`Item`。
2. `ProjectSettings/Physics2DSettings.asset` 的 `m_LayerCollisionMatrix`（256 hex，按每层 uint32 小端解码）中：
   - `Ground(3) ↔ Player(6)` = **开**；`Tombstone(9) ↔ Player(6)` = **关**；`Tombstone(9) ↔ Ground(3)` = 关；`Item(8) ↔ Player(6)` = 关。
   - 结论：**墓碑当前不会与玩家碰撞**（默认行为即"无碰撞"）。
3. `Physics2D.IgnoreCollision` 官方文档明确："Collision layers are first checked … and **if not then no interactions take place**" → 它**无法**把被矩阵关闭的层对重新打开。
4. `Collider2D.includeLayers` 官方文档："specify additional Layers that this specific Collider2D instance can contact" → 可越过矩阵强制接触，但**只影响碰撞体之间的接触**，不影响射线（玩家地面检测用的是 `Physics2D.Raycast` + `groundMask=Ground`）。
5. 因此要让"实体墓碑"能被玩家站着并起跳，墓碑必须真正处于 **Ground 层**（用户已确认要"视为实体/地面"）。
6. 现有移动地面（`BalanceElevator`、`DayNightElevator`、`doorwithtrigger`、`botton`）**都用 `transform.position` 逐帧平移**，且平台在 `Ground` 层（玩家的地面射线只认同层）。它们普遍是 Kinematic 或干脆无刚体 → **物理碰撞回调不可靠**，需要主动做重叠检测。
7. `墓碑控制.prefab`（即 `TombstoneService`）目前**未出现在任何场景中**（`SampleScene`/`game1`/`game2` 均无）——这是既有状态，需你在编辑器里放入场景后本功能才会生效。

## 设计决策（已与用户确认）

- 两个开关放在 **`TombstoneService`** 上（一处调整，作用于所有生成的墓碑）。
- `collideWithPlayer = true` → 该墓碑实例置于 **Ground 层**：玩家被挡住、可站上去并正常起跳（并成为玩家的合法"地面"）。
- `collideWithPlayer = false` → 保持 **Tombstone 层**：玩家可穿过。
- 两个开关**默认 false**，与当前行为完全一致（不改变现有玩法）。
- 悬停墓碑的"移动地面"判定层：默认解析为 `Ground` 层（Inspector 可改），**不会**粘到玩家/道具身上。

## 实现步骤（只改一个文件）

**修改 `Assets/Scripts/Tombstone/TombstoneService.cs`**（无需新建文件 / 无需处理 .meta）

### 1. 新增 Inspector 字段

```csharp
[Header("玩家碰撞")]
[Tooltip("勾选：墓碑视为实体/地面，会挡住玩家且玩家可站在其上起跳（放到 Ground 层）；取消：玩家可穿过墓碑。")]
public bool collideWithPlayer = false;

[Header("空中放置")]
[Tooltip("勾选：允许在空中放置墓碑。空中放置的墓碑会悬停在放置点；当有移动的地面碰到它时粘附到该平台并随之移动。")]
public bool allowAirPlacement = false;
[Tooltip("哪些层的物体算作「可粘附的移动地面」。留空(Nothing)时按名称解析为 Ground 层。")]
public LayerMask movingGroundMask;
```

### 2. 新增悬停/粘附状态与探测缓存（私有字段）

```csharp
private bool hovering;              // 当前墓碑是否在空中悬停
private bool attached;              // 是否已粘附到移动平台
private Rigidbody2D hoverRb;        // 悬停/粘附期间驱动位置的刚体
private Transform attachAnchor;     // 粘附平台的 Transform
private Vector3 attachLocalOffset;  // 墓碑在平台本地空间的偏移
private int movingMask;             // 解析后的"移动地面"掩码
private ContactFilter2D movingFilter;
private readonly Collider2D[] overlapBuffer = new Collider2D[16];
private readonly Dictionary<Collider2D, Vector2> lastCenters = new Dictionary<Collider2D, Vector2>();
private readonly List<Collider2D> staleKeys = new List<Collider2D>();
```

`Awake` 中：在既有单例逻辑之后解析掩码（沿用 `Entity.ResolveGroundMask` 的"按层名称解析"约定）：

```csharp
movingMask = movingGroundMask.value != 0
    ? movingGroundMask.value
    : (LayerMask.NameToLayer("Ground") >= 0 ? 1 << LayerMask.NameToLayer("Ground") : 0);
if (movingMask == 0) Debug.LogWarning("TombstoneService: 未指定 movingGroundMask 且找不到 Ground 层，粘附功能关闭。", this);
movingFilter = new ContactFilter2D { useTriggers = false };
movingFilter.SetLayerMask(movingMask);
```

### 3. 改造 `TryPlaceAtPlayerFeet`：支持空中放置

保留既有地面分支（射线命中 + `placementOffset`），新增空中分支：

```csharp
if (player == null) return false;

bool grounded = player.IsGroundDetected();
if (!grounded && !allowAirPlacement)
{
    Debug.Log("[墓] 空中放置未开启且玩家不在地面，放置无效。");
    return false;
}

Vector2 pos;
if (grounded) { /* 既有逻辑：TryGetGroundHit(ignoreTombstones:true) → hit.point + placementOffset，退化用 GroundCheck.position */ }
else          { pos = (Vector2)player.GroundCheck.position + placementOffset; }  // 悬停在脚底当前高度

ReplaceTombstone(pos, hovering: !grounded);
return true;
```

### 4. 改造 `ReplaceTombstone(Vector2, bool hovering)`

在销毁旧实例前调用 `ClearHoverState()`；实例化后：

- 保留既有"设置 Tombstone 层"逻辑；
- 若 `collideWithPlayer`，在之后**递归把层改为 `Ground`**（找不到 Ground 层则告警）。这样玩家可站上去并被玩家的地面射线识别；
- 若本次是空中放置，调用 `BeginHover()`。

### 5. 新增悬停与粘附逻辑

- `BeginHover()`：取/加 `Rigidbody2D`，设 `bodyType = Kinematic`、`gravityScale = 0`、`velocity = 0`；`hovering = true; attached = false; lastCenters.Clear();`
- `FixedUpdate()`（仅当 `hovering` 且实例有效）：
  - 已粘附 → `attachAnchor` 为空则退化为悬停；否则 `hoverRb.position = attachAnchor.TransformPoint(attachLocalOffset);`
  - 未粘附 → `TryAttachToMovingGround()`
- `TryAttachToMovingGround()`：用 **重叠检测**（不依赖碰撞回调，因为平台是用 `transform.position` 平移的）：
  ```csharp
  Bounds b = selfCol.bounds;
  int count = Physics2D.OverlapBox(b.center, b.size, 0f, movingFilter, overlapBuffer);
  // 第 1 遍：只读取 lastCenters，判断谁在移动
  //   moving = lastCenters.TryGetValue(c, out prev) && (c.bounds.center - prev).sqrMagnitude > 1e-6f
  //   排除自身与自身子物体；moving → AttachTo(c) 并 return
  // 第 2 遍：写回各自的 bounds.center 采样；剔除已销毁(null)的键
  ```
  用"上一物理帧位置 vs 本帧位置"判定移动，正好对应需求"**移动的**地面碰到它"，静止的墙/静态地形不会被粘附。
- `AttachTo(Collider2D c)`：平台根 = `c.attachedRigidbody != null ? c.attachedRigidbody.transform : c.transform`；记录 `attachLocalOffset = platform.InverseTransformPoint(hoverRb.position)`；`attached = true`；打印一条 `[墓] 墓碑已粘附到移动地面：<name>`。**不采用 SetParent**，避免平台被销毁时连带销毁墓碑。
- `ClearHoverState()`：复位 `hovering/attached/hoverRb/attachAnchor` 并清空 `lastCenters`。

## 不改动的部分

- `TombstoneMarker`、`GraveItem`（放置键仍是 **S**）、`PlayerTombstoneTeleport` / `PlayerGraveTeleportController`（传送键仍是 **W**）均不需要改动：墓碑位置变化会通过 Transform 自动反映到 `FeetWorldPosition`，传送目标随之移动。
- 不改 `ProjectSettings`（不动碰撞矩阵、不改层命名）。
- 不新建文件，因此不涉及 .meta 规范化。

## 前置条件与验证

前置：把 `Assets/Prefabs/墓碑控制.prefab` 拖入场景（当前三个场景都没有它），确认其 `tombstonePrefab`/`placementOffset` 已接线。

在 Unity 中进入 Play 验证：

1. **默认开关全关**：与改动前完全一致——只在地面可放置，玩家可穿过墓碑。
2. `allowAirPlacement = false`：在空中按 S → 无墓碑出现，Console 打印"空中放置未开启…"。
3. `allowAirPlacement = true`：起跳后在空中按 S → 墓碑出现在脚底高度且**悬停不下落**（Hierarchy 里其 Rigidbody2D 显示 Kinematic、Gravity Scale 0）。
4. 让一块移动地面（`DayNightElevator` / `doorwithtrigger` / `botton` 驱动的门）移到悬停墓碑处 → 墓碑随之移动；Console 打印"已粘附到移动地面"。静止地形不触发粘附。
5. `collideWithPlayer = true`：玩家被墓碑挡住，可站在其上并正常起跳（`IsGroundDetected()` 为真）；`= false`：玩家可穿过。
6. 粘附后按 W 传送 → 玩家落到墓碑**当前**位置。

## 风险与注意

- 粘附依赖"上一帧→本帧"位移判定，平台至少在重叠处停留 2 个物理帧才会被识别为"移动"；匀速平台（本项目均为 `MoveTowards` 匀速）可满足。
- 若平台在被粘附后中途停止移动，墓碑会停在平台上（继续保持父子跟随关系），符合"随平台移动"的语义。
- 空中放置时用 `placementOffset`（预制体里是 `y=0.5`），墓碑底边落在玩家脚底高度。
