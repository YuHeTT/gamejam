# 道具能力「幕」：漂浮 / 卡住机制

## Context（背景）

上一步已搭好道具框架（`Item` 基类 + `PlayerItemController`，J 拾取/交换、I 使用）。现在实现第一个具体能力「幕」：

- 拾取「幕」→ 玩家进入**漂浮**状态：角色高度减半（视觉与碰撞箱 y 轴都减半）、重力减半、禁用跳跃。
- 丢弃「幕」→ 恢复初始状态；**但**若此时正处在低矮空间（恢复到全高会与地形重叠），则进入**卡住**状态：左右移动播放行走动画但不发生位移（原地踏步）、无法跳跃，直到重新拾取「幕」回到漂浮状态。
- 道具丢弃逻辑（通用，对所有道具生效）：从玩家当前位置**自由落体**直到落到最近地面；**落在平台边缘不滑落**（即使重心不在平台上）。

已确认取舍：
1. 漂浮/卡住用**新增状态机状态**实现（`PlayerFloatState`、`PlayerStuckState`）。
2. 漂浮状态下**同时禁用跳跃与冲刺**。

### 关键现场数据（已核实）
- 玩家 GameObject fileID `541815879`，**Layer 6**（不是 7）。
- `BoxCollider2D`（fileID `541815882`）：`size = (0.8169811, 1.9241153)`，`offset = (-0.076797545, -0.34630126)`，非 Trigger。→ 脚底本地 y = offset.y − size.y/2 ≈ **-1.3084**。
- `GroundCheck` 子物体（fileID `1517781209`）本地 y = **-1.272**（在碰撞体内，压缩后仍在）。
- 视觉子物体 `Animator`（fileID `317415028`，挂 `Animator` + `SpriteRenderer`）本地位置 `(0.4, 0, 0)`、`localScale = (1,1,1)`。
- **缩放根 Transform 是错误做法**：会把 GroundCheck 的 y 偏移一起减半（脚部检测点上升），故改为直接改 `BoxCollider2D` + 单独压扁视觉子物体。
- 清理前一版遗留问题：上一轮把 `Player↔Item` 碰撞错误地关到了 Layer **7**，实际玩家是 Layer **6**，需修正。

## 实现方案

### 1. 新增 `Assets/Scripts/Player/PlayerFloatState.cs`

漂浮状态：作为独立状态接管漂浮期间的移动与动画。

- `Enter()`：`base.Enter()`；`player.isFloating = true`；`player.SetSquashed(true)`；`rb.gravityScale = player.gravityScale * player.floatGravityMultiplier`。
- `Update()`：`base.Update()`；`player.HorizontalMoveController()`；每帧维持半重力；按 grounded/输入驱动动画布尔（见下）。
- `Exit()`：`base.Exit()`；`player.isFloating = false`；清除 `Move/Idle/Jump` 三个布尔。

动画复用现有参数（控制器无 Float 参数）：地面且移动 → `Move`；地面且静止 → `Idle`；空中 → `Jump`。

```csharp
private void UpdateFloatAnim()
{
    bool grounded = player.IsGroundDetected();
    bool moving   = xInput != 0;
    player.anim.SetBool("Idle", grounded && !moving);
    player.anim.SetBool("Move", grounded && moving);
    player.anim.SetBool("Jump", !grounded);
}
```

### 2. 新增 `Assets/Scripts/Player/PlayerStuckState.cs`

卡住状态：

- `Enter()`：`base.Enter()`；`player.isStuck = true`；`player.SetSquashed(true)`（保持压扁）；`rb.gravityScale = player.gravityScale`（恢复常规重力）。
- `Update()`：`base.Update()`；**水平速度强制为 0**（`player.SetVelocity(0, rb.velocity.y)`）；按 `xInput` 驱动 `Move/Idle` 布尔 → 实现"原地踏步"；`Jump` 保持 false。
- `Exit()`：`base.Exit()`；`player.isStuck = false`；清除相关布尔。

> `Move` 布尔为 true → 动画器切到 playerMove（走路动画）；速度被置 0 → 不产生位移。

### 3. 新增 `Assets/Scripts/Item/MuItem.cs`

「幕」道具：能力为**被动**（拾取即生效，丢弃即结束）。

```csharp
public class MuItem : Item
{
    public override void OnPickUp(Player player) => player.EnterFloat();
    public override void OnDrop(Player player, Vector2 worldPos) => player.TryExitFloat();
}
```

### 4. 修改 `Assets/Scripts/Player/Player.cs`

- 新增字段：
  - `[Header("FloatInfo")] public floatGravityMultiplier = 0.5f; public squashMultiplier = 0.5f;`
  - `public bool isFloating; public bool isStuck;`
  - 状态：`public PlayerFloatState floatState; public PlayerStuckState stuckState;`
- `Awake()`：实例化 `floatState`（anim bool 传 `"Idle"`）、`stuckState`（传 `"Idle"`）。
- `Start()`：在 `base.Start()` 之后缓存原始数据：`boxCol = GetComponent<BoxCollider2D>()` 的 `size/offset`、`anim.transform` 的 `localScale/localPosition`。
- 新增方法：
  - `SetSquashed(bool)`：按 `squashMultiplier` 改 `boxCol.size.y`，**保持碰撞体底部不动**（`offset.y = bottom + newH/2`）；视觉子物体 `localScale.y *= 0.5` 并以碰撞体底部为锚点平移 `localPosition.y`，使视觉底边不动；末尾 `Physics2D.SyncTransforms()`。恢复时用缓存的原始值还原。
  - `HasHeadroom()`：只用"从压缩后顶部到全高顶部"这段区域做 `Physics2D.OverlapBox(..., whatIsGround)`；无重叠即净空足够。底部不动，所以只需检测这段新增高度，避免误判脚下的地面。
  - `EnterFloat()`：`stateMachine.ChangeState(floatState)`（已在漂浮态则忽略）。
  - `TryExitFloat()`：若当前非漂浮态直接返回；`HasHeadroom()` 为真 → `SetSquashed(false)` + `ChangeState(落地 ? idleState : airState)`；否则 → `ChangeState(stuckState)`；随后 `rb.gravityScale = gravityScale`。
- 输入门控（漂浮/卡住期间禁用跳跃与冲刺，并清掉缓冲避免解除后误触发）：
  - `CheckJumpInput()`：在读取按键前插入 `if (isFloating || isStuck) { jumpBufferTimer = 0; return; }`
  - `CheckDashInput()`：计时衰减后插入 `if (isFloating || isStuck) { dashBufferTimer = 0; return; }`

### 5. 修改 `Assets/Scripts/Item/Item.cs` — 通用丢弃落体

在 `ExitCarriedState` 的物理处理中，令道具"直落且不滑落"：

```csharp
rb.constraints = RigidbodyConstraints2D.FreezePositionX | RigidbodyConstraints2D.FreezeRotation;
rb.gravityScale = 1f;
rb.velocity = Vector2.zero;
rb.angularVelocity = 0f;
rb.position = worldPos;
```

`FreezePositionX` 保证沿 X 不动（直上直下自由落体、落地后不会滑下平台边缘）；`FreezeRotation` 防止重心悬空时倾倒。

### 6. 修改 `ProjectSettings/Physics2DSettings.asset` — 修正碰撞矩阵

把 "Player↔Item 不碰撞" 从 Layer7 改为 **Layer6**：`m_LayerCollisionMatrix` 的 byte[7] 与 byte[8] 的 bit6 清零 → `byte[7] = 0xBF, byte[8] = 0xBF`，其余 `0xFF`（共 128 字节 / 256 个十六进制字符）。

副作用（符合预期）：道具下落时会**穿过玩家身体**落到地面，不会被玩家顶住。

### 7. 编辑器手动配置（用户操作）

- 新建道具对象（或 Prefab）：`SpriteRenderer` + `Rigidbody2D`（Dynamic、Freeze Rotation Z、Gravity Scale 1）+ `Collider2D`（非 Trigger）+ **`MuItem`** 脚本；Layer = `Item`；摆到平台上。
- 无需新增动画资源：漂浮/卡住复用现有 `Idle/Move/Jump` 动画（角色被压扁，观感即为"扁平"状态）。

## 验证方式

1. **编译**：Unity 无报错；Player 的 Inspector 出现 `Float Info` 分组与 `isFloating/isStuck` 勾选框。
2. **拾取生效**：站到「幕」旁按 J → 角色视觉一瞬间压扁到约一半高度、碰撞体变矮（Scene 视图可见）；Inspector `isFloating = true`。
3. **低重力**：压扁后走到平台边缘落下，下落明显变慢；按空格与 Shift 均无反应。
4. **正常恢复**：在开阔处按 J 丢弃（或换走）→ 角色恢复全高、恢复重力、可跳可冲。
5. **卡住**：先拾取「幕」压扁后钻进低矮通道，在里面按 J 丢弃 → 角色**保持压扁**且进入 `isStuck = true`；按 A/D 有走路动画但位置不动；空格/Shift 无效。
6. **解除卡住**：在卡住处重新按 J 拾取「幕」→ 回到漂浮状态，可正常走出通道，再在开阔处丢弃恢复正常。
7. **落体不滑落**：在平台边缘持道具按 J 丢弃 → 道具竖直下落、停在平台边缘，**重心悬空也不滑落**；道具穿过玩家身体而不会卡在头顶。
8. **通用性**：任一其他道具丢弃都应表现为竖直下落到最近地面。

## 注意事项

- `AutoSyncTransforms = 0`：改完碰撞体尺寸后立刻做物理查询，必须在 `SetSquashed` / `HasHeadroom` 里调用 `Physics2D.SyncTransforms()`。
- 碰撞体底部保持不动是"不陷地/不跳起"的关键；不要改为缩放根 Transform（会带上 GroundCheck 一起缩放）。
- `HasHeadroom` 用 `whatIsGround`（Layer 3）掩码，玩家自身在 Layer 6，不会被误检。
- 漂浮/卡住状态会驱动 `Move/Idle/Jump` 三个布尔，`Exit()` 必须全部清零，否则动画器会残留状态。
- 若在冲刺途中拾取「幕」，属于边缘情况：冲刺会在自身 `Exit` 里把重力写回 5，下一帧漂浮状态会重新覆盖为半重力，可自愈。
