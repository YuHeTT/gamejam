# 道具与能力系统框架

## Context（背景）

项目已从 2D 动作游戏改造为 2D 纯解谜游戏（敌人/攻击/滑墙/二段跳均已移除）。现在要加入解谜核心机制：**场景中的可拾取"道具"**。

需求：
- 道具与平台有碰撞，静止放在平台上，有静止动画（暂定空、不播放）。
- 每件道具对应一种特殊能力。
- 玩家与道具较接近时按 **J** 拾取；若已有道具则**交换**（单道具栏，最多持有 1 个）。
- 玩家按 **I** 使用当前持有道具的能力。

本次**只搭框架**，具体能力效果后续由子类填入。已确认的三个取舍：
1. 能力用「每种道具一个 `Item` 子类，重写虚方法」实现（契合项目纯代码风格）。
2. 本次**不创建**示例道具、不摆放场景（由用户在编辑器自行创建道具对象）。
3. **新增 `Item` 图层并关闭 Player↔Item 碰撞**，防止玩家把道具推着走。

## 设计要点

- `Item` 是**具体（非抽象）MonoBehaviour**，提供 `OnPickUp / UseAbility / OnDrop` 虚方法；每种道具写一个子类 override `UseAbility` 即可。
- 输入（J/I）、单槽位、拾取检测、交换时序集中在**新组件 `PlayerItemController`**（挂在 Player 上），**不改动 `Player.cs`**。
- 持有时**不 `SetActive(false)`**，而是关闭 `rb.simulated / collider.enabled / renderer.enabled`，保留 GameObject 激活（保证子类能力里能正常用协程、生成特效）。
- 拾取检测：`Physics2D.OverlapCircleAll` + `GetComponentInParent<Item>()` 类型过滤 + 取最近；仅在按键时执行，无每帧 GC。
- 交换时序：先把旧道具 `ExitCarriedState` 放回世界（用 `rb.position` 设置），再拾取新道具；操作后加冷却，防止同一帧连换。

## 新增文件

### `Assets/Scripts/Item/Item.cs`（含 `Assets/Scripts/Item.meta`、`Item.cs.meta`）

世界中的道具，同时承载该道具的能力逻辑。**组件 `Rigidbody2D`、`Collider2D`、`SpriteRenderer` 须与 `Item` 在同一 GameObject 上**。

```csharp
using UnityEngine;

/// <summary>世界中的道具：可被拾取的物理物体，同时承载该道具的能力逻辑</summary>
public class Item : MonoBehaviour
{
    [Header("ItemInfo")]
    public string itemName = "未命名道具";
    public Sprite icon;                       // 预留：UI 用，暂不接入

    [Header("DropInfo")]
    public Vector2 dropOffset = Vector2.zero; // 从玩家身上放回世界时的偏移

    protected SpriteRenderer sr;
    protected Rigidbody2D rb;
    protected Collider2D col;

    public bool IsCarried { get; private set; }
    public Player Holder { get; private set; }

    protected virtual void Awake()
    {
        sr  = GetComponentInChildren<SpriteRenderer>();
        rb  = GetComponent<Rigidbody2D>();
        col = GetComponent<Collider2D>();
    }

    #region 能力扩展点（子类在此填写具体能力）
    /// <summary>进入道具栏时触发</summary>
    public virtual void OnPickUp(Player player) { }
    /// <summary>按 I 使用能力。返回 true 表示该道具被消耗（从槽位移除并销毁）</summary>
    public virtual bool UseAbility(Player player) => false;
    /// <summary>离开道具栏时触发（交换/丢弃）</summary>
    public virtual void OnDrop(Player player, Vector2 worldPos) { }
    /// <summary>放回世界的位置，子类可重写</summary>
    public virtual Vector2 GetDropPosition(Vector2 playerPos) => playerPos + dropOffset;
    #endregion

    #region 世界/持有状态切换（由 PlayerItemController 调用）
    public void EnterCarriedState(Player player)
    {
        IsCarried = true;
        Holder    = player;
        SetWorldPresence(false);
        OnPickUp(player);
    }

    public void ExitCarriedState(Player player, Vector2 worldPos)
    {
        IsCarried = false;
        Holder    = null;
        if (rb != null)
        {
            rb.velocity        = Vector2.zero;
            rb.angularVelocity = 0f;
            rb.position        = worldPos;   // 必须走 rb.position（见"坑"）
        }
        transform.position = worldPos;
        SetWorldPresence(true);
        OnDrop(player, worldPos);
    }

    // 关闭物理与渲染、但保留 GameObject 激活
    protected void SetWorldPresence(bool present)
    {
        if (rb  != null) rb.simulated = present;
        if (col != null) col.enabled  = present;
        if (sr  != null) sr.enabled   = present;
    }
    #endregion
}
```

### `Assets/Scripts/Player/PlayerItemController.cs`（含 `.meta`）

挂在 Player 上，负责 J 拾取/交换、I 使用、单槽位与检测。

```csharp
using System;
using UnityEngine;

/// <summary>玩家道具栏：J 拾取/交换，I 使用。挂在 Player 上</summary>
public class PlayerItemController : MonoBehaviour
{
    [Header("Refs")]
    public Player player;                // 留空则自动向上查找
    public Transform pickUpCheck;        // 检测中心，留空用自身

    [Header("PickUpInfo")]
    public float pickUpRadius = 1.2f;
    public LayerMask whatIsItem = ~0;    // 建议设为 Item 层；留 Everything 也能靠类型过滤工作
    public float pickUpCooldown = 0.15f; // 交换/拾取后的再拾取冷却
    private float pickUpCooldownTimer;

    [Header("Keys")]
    public KeyCode pickUpKey = KeyCode.J;
    public KeyCode useKey    = KeyCode.I;

    public Item CurrentItem { get; private set; }
    public bool HasItem => CurrentItem != null;
    /// <summary>槽位变化广播，未来接 UI 直接订阅</summary>
    public event Action<Item> OnItemChanged;

    private void Awake()
    {
        if (player == null)      player      = GetComponentInParent<Player>();
        if (pickUpCheck == null) pickUpCheck = transform;
    }

    private void Update()
    {
        if (pickUpCooldownTimer > 0) pickUpCooldownTimer -= Time.deltaTime;

        if (Input.GetKeyDown(pickUpKey)) TryPickUp();
        if (Input.GetKeyDown(useKey))    UseCurrentItem();
    }

    /// <summary>拾取/交换。返回是否发生了交互</summary>
    public bool TryPickUp()
    {
        if (pickUpCooldownTimer > 0) return false;

        Item target = FindNearestItem();
        if (target == null || target == CurrentItem) return false;

        if (CurrentItem != null)          // 交换：先把旧道具放回世界
        {
            Item old = CurrentItem;
            CurrentItem = null;
            old.ExitCarriedState(player, old.GetDropPosition(player.transform.position));
        }

        CurrentItem = target;
        target.EnterCarriedState(player);
        OnItemChanged?.Invoke(target);
        pickUpCooldownTimer = pickUpCooldown;
        return true;
    }

    public bool UseCurrentItem()
    {
        if (CurrentItem == null) return false;

        bool consumed = CurrentItem.UseAbility(player);   // 能力实现在这里被调用
        if (consumed)
        {
            Destroy(CurrentItem.gameObject);
            CurrentItem = null;
            OnItemChanged?.Invoke(null);
        }
        return true;
    }

    /// <summary>找最近的可拾取道具</summary>
    private Item FindNearestItem()
    {
        Vector2 center = pickUpCheck.position;
        Collider2D[] hits = Physics2D.OverlapCircleAll(center, pickUpRadius, whatIsItem);

        Item nearest  = null;
        float bestSqr = float.MaxValue;
        foreach (Collider2D hit in hits)
        {
            Item item = hit.GetComponentInParent<Item>();
            if (item == null || item.IsCarried) continue;   // 类型过滤同时排除玩家自身碰撞体

            float sqr = ((Vector2)item.transform.position - center).sqrMagnitude;
            if (sqr < bestSqr) { bestSqr = sqr; nearest = item; }
        }
        return nearest;
    }

    private void OnDrawGizmosSelected()   // 与 Entity 的 Gizmo 风格一致，便于调半径
    {
        Gizmos.color = Color.yellow;
        Vector3 c = pickUpCheck != null ? pickUpCheck.position : transform.position;
        Gizmos.DrawWireSphere(c, pickUpRadius);
    }
}
```

## 修改文件

### `ProjectSettings/TagManager.asset`
把 `layers` 数组索引 **8** 填入 `Item`（Layer 8）。**索引 3（Ground）与 7（Player）名称虽为空但已被使用，不得覆盖。**

### `ProjectSettings/Physics2DSettings.asset`
在 `m_LayerCollisionMatrix` 中**清除 Layer7(Player) 与 Layer8(Item) 的互相碰撞位**（改用 `.asset` 中的整块重写，保证矩阵一致）。平台(3)↔Item(8) 保持开启，道具才能落在平台上。

> 说明：`OverlapCircleAll` 使用传入的 `layerMask`，**不受** Layer Collision Matrix 影响，拾取检测照常工作。

## 需要在 Unity 编辑器完成的一次性配置（用户操作）

1. **挂组件**：选中场景里的 `Player`，Add Component → `PlayerItemController`。
   - （可选）新建子空物体 `ItemCheck` 放在玩家中心附近并赋给 `pickUpCheck`；不建则用玩家原点。
   - `pickUpRadius` 先设约 `1.2`；`whatIsItem` 勾选 `Item` 层。
2. **创建道具对象**（每个道具）：
   - 根物体挂：`SpriteRenderer`（占位图）、`Rigidbody2D`、`Collider2D`（**取消 Is Trigger**）、一个 `Item` 子类脚本；可选 `Animator`（静止动画暂空）。
   - `Rigidbody2D` 建议：`Body Type = Dynamic`、`Gravity Scale = 1`、`Constraints = Freeze Rotation Z`、`Interpolate = Interpolate`、`Collision Detection = Continuous`。
   - 物体 **Layer = Item**；摆在平台上方，靠重力压稳。
3. **写能力**：新建 `class XxxItem : Item` 并 override `UseAbility(Player player)`（需要消耗则 `return true`）。

## 验证方式

1. **编译**：Unity 无报错，Player 上出现 `PlayerItemController`；选中 Player 时 Scene 视图出现黄色拾取半径线框圆。
2. **拾取**：空槽走近道具按 J → 道具从画面消失（物理+渲染关闭），槽位记录该道具。再按 J 无变化。
3. **交换**：持有 A 后走到 B 旁按 J → B 消失、A 出现在玩家位置；冷却过后 A 可被重新拾取；确认不会同一帧把刚放下的 A 又捡回。
4. **使用**：按 I → 触发 `UseAbility`（占位先 `Debug.Log`）；空槽按 I 无异常、无日志。
5. **消耗分支**：把某子类 `UseAbility` 改为 `return true`，按 I 后道具被销毁且槽位清空。
6. **不被推动**：玩家反复撞击道具，道具位置不漂移（碰撞矩阵生效）。
7. **无重复检测**：已持有的道具不会再被 `FindNearestItem` 找到（`IsCarried` + 碰撞体关闭双保险）。
8. **事件**：临时脚本订阅 `OnItemChanged`，确认拾取/交换/消耗三条路径都触发。

## 注意事项（坑）

- `AutoSyncTransforms = 0`：放回世界时必须用 `rb.position = worldPos`，否则物理查询会用旧位姿，出现"刚放下就被重新拾取"。
- `Player.Flip()` 对整个 transform 做 `Rotate(0,180,0)`：**不要把道具 reparent 到玩家**，否则会被镜像。将来做手持显示应放在专用持有点。
- `OverlapCircleAll` 一定会返回玩家自身 `BoxCollider2D`，靠 `GetComponentInParent<Item>()` 过滤掉，**不要**改成用 tag 粗筛而丢掉该过滤。
- 检测只在 `GetKeyDown` 时执行，不要挪进 `Update` 无条件调用，避免每帧分配。
- `Item` 的 `Rigidbody2D`/`Collider2D` 必须与其在同一 GameObject，子物体上的碰撞体会导致 `GetComponent` 取空、`SetWorldPresence` 静默失效。
