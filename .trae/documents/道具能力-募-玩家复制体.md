# 道具能力「募」——玩家复制体

## Context（背景与目标）

道具框架（[Item.cs](file:///k:/Unity/Project/gamejam/Assets/Scripts/Item/Item.cs)）已支持「每种道具一个子类、重写虚方法」，并已实现「幕（漂浮）」「暮（昼夜）」「蓦（跳跃倍率 + L 冲刺）」。本次新增第 4 个道具「募」：

- 持有「募」时按 **L**，在玩家当前位置召唤一个**玩家复制体**；
- 复制体的碰撞箱 / 图像 / 动画与玩家一致，但**与玩家、与其它复制体之间没有碰撞体积**；
- 复制体**镜像玩家的 A/D（左右）与 K（跳跃）输入**；
- 按 **S** 启用 / 断开连接（决定复制体是否继续模仿）；
- 场景中最多同时存在 **n=3** 个（Inspector 可调），达到上限后按 L 无效；
- **丢弃「募」→ 复制体保留但立即断开连接**；之后再捡回「募」默认仍是断开状态，需再按 S 启用（用户确认）。

## 关键设计决策

### 1. 复制体复用 `Entity`
`PlayerClone : Entity`，直接继承 [Entity.cs](file:///k:/Unity/Project/gamejam/Assets/Scripts/Entity.cs) 已有的能力：
- `anim` / `rb` 自动解析（`GetComponentInChildren<Animator>()` / `GetComponent<Rigidbody2D>()`）
- 三点向下射线的地面检测 `IsGroundDetected()`（用 `groundCheck` + `groundCheckDistance` + `groundCheckDeviate`）
- `SetVelocity`（= 设速度 + 自动翻转）、`FlipController`（Y 轴 180° 翻转，`transform.Rotate(0,180,0)`）
- `maxFallSpeed` 下落限速（`Entity.Update`）

需要给 `Entity` 增加 3 个**只读访问器**，让复制体能从玩家身上拷贝参数（`protected` 字段子类无法通过基类实例读取）：
`GroundCheckDistance` / `GroundCheckDeviate` / `GroundMask`。

### 2. 运行时以玩家为模板生成，不需要预制体
在 [CloneManager](#) 里按玩家现场拼装：
- **根对象**：`position` / `rotation` / `localScale` 取自玩家；`layer` 取玩家所在层（当前为 6）。
- **Rigidbody2D**：拷贝 `mass / linearDrag / angularDrag / gravityScale / constraints / collisionDetection / interpolation / sharedMaterial`。
- **BoxCollider2D**：拷贝 `size / offset / sharedMaterial`，`isTrigger = false`。
- **子对象 `Animator`**（SpriteRenderer + Animator）：`localPosition` / `localScale` 取自玩家视觉子物体；SpriteRenderer 拷 `sprite / color / sortingLayerID / sortingOrder / sharedMaterial / flipX / flipY`；Animator 设 `runtimeAnimatorController`。**不挂**玩家视觉子物体上的其它脚本（如 [PlayerShearVisual.cs](file:///k:/Unity/Project/gamejam/Assets/Scripts/Player/PlayerShearVisual.cs)，它依赖 `Player`）。
- **子对象 `GroundCheck`**：`localPosition` / `localScale` 取自玩家的 GroundCheck。

> 玩家视觉子物体名称为 `Animator`，本地坐标 `(0.4, 0, 0)`；GroundCheck 本地坐标 `(-0.073, -1.272, 0)`。

### 3. 无碰撞体积用 `Physics2D.IgnoreCollision`，不改层碰撞矩阵
每个复制体生成时：
- `Physics2D.IgnoreCollision(复制体碰撞体, 玩家碰撞体, true)`
- 与**每个已有复制体**互相 `IgnoreCollision`

复制体保留与 `Ground` 层的碰撞。**不修改** `ProjectSettings/Physics2DSettings.asset` 与 `TagManager.asset`（避免层矩阵字节编码出错，且无需新增图层）。

### 4. 输入镜像（仅 A/D 与 K）
在 `PlayerClone.Update` 中：
- **水平**：`x = connected ? PlayerState.xInput : 0f` → `rb.velocity = new Vector2(x * moveSpeed, rb.velocity.y)` → `FlipController(x)`
- **跳跃**：`connected && IsGroundDetected() && Input.GetKeyDown(KeyCode.K)` → `rb.velocity = new Vector2(rb.velocity.x, jumpSpeed)`
- **长按更高**（复刻玩家 [JumpHeightController](file:///k:/Unity/Project/gamejam/Assets/Scripts/Player/Player.cs#L142-L152)）：上升中若未按住 K → `rb.gravityScale = gravityScale * fallMultiplier`，否则 `gravityScale`
- **动画**：与玩家状态机一致地互斥设置 `Idle / Move / Jump` 三个 bool，并每帧 `anim.SetFloat("yVelocity", rb.velocity.y)`（依据 [PlayerState.cs](file:///k:/Unity/Project/gamejam/Assets/Scripts/Player/PlayerState.cs)）

### 5. 连接状态（全局，向第一个复制体统一）
- `connected` 为**全局**开关，初始 `true`
- 新召唤的复制体直接采用当前 `connected` → 天然满足「第一个默认启用连接、后续复制体跟随第一个的状态」
- 按 S 切换 `connected`，逐帧作用于所有复制体（断开 = 输入视为 0，物理照常：会下落、落地站住）
- **丢弃「募」→ `connected = false` 且不销毁复制体**；**重新拾取「募」不改动 `connected`**（保持断开，需再按 S）

### 6. 上限
`maxClones = 3`（Inspector 可调）。`clones.Count >= maxClones` 时按 L 直接返回，无效果。

## 场景侧设置（需你手动完成）

1. **确认 Player 上已挂 `PlayerItemController`**。我读到的磁盘版 `SampleScene.unity` 里 Player 只有 4 个组件（Transform / Player / BoxCollider2D / Rigidbody2D），没有 PlayerItemController——如果你的改动还没保存，请先保存。
2. 新建「募」道具对象：`SpriteRenderer` + `Rigidbody2D`（Dynamic、Freeze Rotation Z、Gravity Scale 1）+ `Collider2D`（非 Trigger）+ `SummonItem`，**Layer = Item**。
3. （可选）把 `CloneManager` 挂到场景中任意对象上，用于在 Inspector 调 `maxClones`；未放置时会在首次使用时自动创建（默认 3）。

## 验证方式

在 Unity 中重新导入后：

1. **编译**：`Assets/Scripts` 无编译错误（可全局搜索 `SummonItem` / `PlayerClone` / `CloneManager` 确认无残留引用报错）。
2. **Play 模式**依次验证：
   - 拾取「募」→ 按 **L** → 玩家原地出现复制体；按 A/D 与 K，复制体同步移动/跳跃，动画与玩家一致；
   - 复制体与玩家、复制体之间可以互相穿过（无碰撞），但都会踩在地面上、不会掉下去；
   - 按 **S** → 复制体停止响应输入（悬空则下落、落地站住）；再按 S → 恢复模仿；
   - 连按 L 生成 3 个后，第 4 次按 L 无效；
   - **丢弃「募」** → 复制体保留但立即停止模仿；重新拾取「募」后仍是停止状态，按 S 才恢复。
3. **回归**：「幕 / 暮 / 蓦」三个道具行为不受影响（J 拾取/丢弃、I 使用、K 跳跃、L 冲刺）。

## 备注 / 已知风险

- 复制体与**道具**（Layer 8）是否碰撞，取决于 `Physics2DSettings.asset` 里 Player↔Item 的层矩阵改动是否真正生效。现有的矩阵改动落在字节 7/8，与 Unity「每层 4 字节、小端」的编码位置（应为字节 25 / 32）对不上，可能并未生效。本次不改动该文件；若发现复制体被道具挡住，可另外用 `Physics2D.IgnoreLayerCollision(6, 8, true)` 在运行时兜底。
- 复制体为运行时拼装，玩家后续若新增「必须挂在视觉子物体上才生效」的脚本，复制体不会带上（按设计如此）。
